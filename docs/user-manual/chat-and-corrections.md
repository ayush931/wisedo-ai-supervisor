# Ask about the approved process and correct an answer

Active site owners, supervisors and operators can ask questions in **Today**. Each person's
conversation is private to its author, including from other supervisors. Answers use the published
process snapshot and its readable evidence. Candidates never become answer authority. A stale
snapshot is labelled; an answer whose cited evidence or approval is no longer available is withheld.

Use **This is wrong** on your answer or a visible investigation result. Explain the problem.
You may include a proposed claim, typed value and evidence. Submitting a chat correction shares
only that selected question and answer with authorized site reviewers; it does not share the rest
of the conversation. Missing details remain visible as requirements for review.

A different human owner or supervisor must review the correction with recent authentication.
Operators may correct their own answers but cannot review or approve. Approval records the
corrected fact and its regression case together. **Approved — awaiting snapshot** means it has
not reached new answers yet. A human must publish the approved process snapshot using the
existing publication action. New questions then use that snapshot for all authorized site members.

An answer citing the exact corrected fact displays **updated after a correction by** the reviewer
and date. An answer citing an old or different fact receives no correction label. The site counter
counts approved corrections once in the site's calendar month, including approvals awaiting
publication. Legacy sites without a timezone use UTC. It is an approval count, not a quality score.
